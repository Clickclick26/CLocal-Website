# CLocal Landing Page

Marketing site for **CLocal** — a video-first local discovery app connecting consumers, micro-influencers, and bricks-and-mortar businesses.

## Brand colors

- Vibrant Teal `#008080`
- Bright Sage `#77DD77`
- Intense Turquoise `#00FFFF`

## Run locally

Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 5173
```

Then visit http://localhost:5173
